# ThemeForge Production

One deployable application combining Phases 1–4: theme-page portfolio management, AI content generation, automated voice/video/caption production, approval-first TikTok export, offers/revenue/cost tracking, SCALE/TEST/PAUSE revenue autopilot, login/authentication, PostgreSQL persistence, TikTok OAuth scaffolding, and Docker deployment.

## Railway deployment

The production service is designed to run from the included Dockerfile with PostgreSQL provided through `DATABASE_URL`.

## Real API connections

Set OpenAI, Pexels, and TikTok credentials as server-side environment variables. The app intentionally defaults to mock/local modes until credentials are provided.

## $10K/month target

$10,000/month is an operating target, not a guarantee. ThemeForge is designed to shorten experimentation cycles and allocate more content production toward pages with better economics.
